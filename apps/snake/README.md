# 🐍 DATA SERPENT — a MINDBOTZ retro snake

A complete, single-file HTML arcade game. Zero dependencies — open it and play.

## Play
```
# any of these:
open apps/snake/index.html          # double-click it
python -m http.server  # then visit /apps/snake/   (from repo root)
```
Arrows / WASD / swipe to steer · SPACE pause · M mute · eat 🍓 to grow & speed up ·
wrap the walls, don't bite the thread · high score saved locally · ↑↑↓↓←→←→BA bonus.
