# resume-rise

## Steps
1. Talk first, type second (10 min): counselor asks about ANY work — cash jobs,
   caretaking, survival logistics, volunteering. It all counts; phrase it true.
   NEVER invent employers, dates, or titles — [NEED] beats a lie that costs a job.
2. Draft (15 min): one page, skills-forward format (gaps don't lead). Contact
   solutions that work unhoused: email + library/shelter address or "available by
   email" — normalize, don't flag.
3. Their voice pass (10 min): read it aloud TO them; they change anything. It's
   theirs.
4. Interview prep (10 min): counselor plays interviewer, 3 questions, twice through.
5. Print 3 copies + save to their email/USB. Nothing retained by us — dignity over
   records.
6. Offer the witness line: `witnessed: <chosen name> — first résumé`. Optional. Read
   aloud if wanted.

## Failure modes
No printer → email + a written note where free printing is (library). Person gets
overwhelmed → stop, save draft to their email, seat stays theirs another day.
