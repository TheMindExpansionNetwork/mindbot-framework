# WORKSHOPS — starter kits anyone can clone and run

*This is a **harm-reduction project**. The harm is concentration: when only the
powerful hold this technology, corruption compounds in the dark. The reduction is
distribution: put the same tools in every hand, in public, with open books — and
take back what was always ours: the means to build. We don't claim a machine that
saves humanity. We claim something we can actually keep: **a machine honest enough
that people can save themselves with it.** That's MindBot. That's the whole bet.*

Each workshop = one SKILL.md, repo conventions throughout (frontmatter, outbox rule,
[NEED] honesty). Runnable by any Operator at commons hours ($1/$4.20/$0 — same seat,
same dignity). Every completion ends the same way: **offer the witness line.**

| workshop | for | walk out with |
|---|---|---|
| resume-rise | anyone job-hunting, incl. unhoused neighbors | a real résumé + interview prep, printed |
| first-business | the idea they've carried for years | one-page plan + first three steps |
| first-song | anyone, no experience | a finished track from the licensed 02_ library |
| learn-the-machine | everyone | their own AI working from their own folder |

Format per session: 50 minutes · counselor assists, human decides · what you make is
yours, full stop · no proof-of-anything required · ends with the witness offer.
