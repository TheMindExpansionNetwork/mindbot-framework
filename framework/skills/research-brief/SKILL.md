# research-brief

## Steps
1. Restate the question in one sentence; get the asker's "done looks like."
2. Gather from ≥3 independent sources (web tool if the runtime has one; otherwise
   repo + dataset + [NEED: web access] honestly).
3. Write the brief: ANSWER (3 sentences max) → KEY FACTS (each tagged
   `[verified: source]` or `[unverified]`) → WHAT WE STILL DON'T KNOW → RECOMMENDED
   NEXT ACTION (one, dated).
4. No fact enters ANSWER unverified. Confidence is part of the deliverable.
5. → outbox if it informs an external move; → collaboration/research/ otherwise.
   Ledger line: `research_brief: <topic>`.

## Failure modes
Sources disagree → say so, show both, don't average truth. Nothing found →
"nothing found" IS the brief; a null result honestly reported beats filler.
